# F1人生 · WDC传奇

一款基于浏览器的 F1 赛车人生模拟游戏。从青涩的储备车手起步，通过赛场表现、车队政治、恋爱社交和投资理财，逐步成长为世界冠军，最终传承衣钵给下一代。

## 游戏特色

### 核心赛车机制
- **真实排位算法**：玩家与 19 名 AI 车手同场排序，保证每场积分唯一分配
- **排位赛-正赛双轨制**：周六排位赛决定起步顺位，周日正赛选择策略（激进/保胎/雨战）
- **车队研发 (R&D)**：完赛获研发点，升级引擎/空动/底盘，草根车队也能逆袭
- **DNF 退赛机制**：激进策略提升名次但增加退赛风险

### 车队与政治
- **10 支真实 F1 车队**：红牛、梅赛德斯、法拉利、迈凯伦等
- **夏休期转会市场**：Q3 季中秘密接触，Q4 结束后正式转会
- **Team Orders**：队内地位低时被要求让车，服从或反抗各有利弊
- **晋升系统**：储备车手 → 试车手 → 正式车手，需满足驾驶/声望/领队关系条件

### 角色与社交
- **围场公共区**：跨车队社交，不受阵营限制
- **5 位可交互 NPC**：记者、技术总监、领队女儿、工程师、摄影师
- **恋爱与婚姻**：从相识到结婚，影响多方面属性
- **宿敌系统**：好感度极低自动结仇，赛道碰撞率大增

### 生涯与传承
- **年度 WDC 争夺**：23 站赛季，积分制世界冠军
- **年薪合同**：豪门底薪高，小车队奖金高
- **投资理财**：房产、基金、副业
- **退役与传承**：退役后开启子女视角，继承部分属性再闯围场

### 随机事件
- FIA 修改技术规则、夏休期受伤、雨战考验、社交媒体风波、引擎爆缸、赞助商签约等

## 快速开始

### 方式一：单文件版（最简单）
下载 `f1-wdc-legend-standalone.html`，用浏览器直接打开即可游玩。所有代码内联，无需任何服务器。

### 方式二：开发版（推荐二次开发）
```bash
git clone https://github.com/your-username/f1-life-wdc-legend.git
cd f1-life-wdc-legend

# 使用 Python
python -m http.server 5000

# 或使用 Node.js
npx serve -l 5000
```
然后访问 `http://localhost:5000`

开发版将 HTML/CSS/JS 分离为独立文件，方便修改和扩展。

### 项目结构
```
f1-life-wdc-legend/
├── index.html                          # 入口页面（引用外部CSS/JS）
├── style.css                           # 游戏样式
├── game.js                             # 游戏核心逻辑
├── f1-wdc-legend-standalone.html       # 单文件版（可直接打开）
├── package.json                        # 项目配置
├── README.md                           # 说明文档
├── LICENSE                             # MIT 许可证
└── .gitignore                          # Git 忽略配置
```

## 游戏流程

1. **创建车手**：选择国籍、性别、名字
2. **选择车队**：从 10 支车队中选择（含 Williams 困难模式）
3. **季度行动**：每赛季 4 个季度，每季度 3 次行动
   - 赛车：排位赛、正赛、模拟器
   - 社交：围场公共区、车队关系、恋爱
   - 个人：训练、投资、休息
4. **赛季结算**：WDC 积分排名、年薪结算、研发结算
5. **传承**：退役后子女继承衣钵
